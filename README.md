Поток приёмок обрывается 2026-08-12. Август календарно полон, а фактом покрыт наполовину: доля строк без приёмок скачет с 5,6–8,2% до 58,5%. Граница окна в Q1 берётся как минимум из двух — текущий календарный месяц и месяц водяного знака полноты факта.

Цена не масштабируется вместе с единицей измерения. Медианная цена ≈20 000 руб при любом коэффициенте: KG (×1) — 20 281, TON (×1000) — 20 158, ROLL50 (×50) — 19 904. Деление на factor_to_base разносит цену внутри одной базовой единицы в 1000 раз. Группа сравнения в Q2 сужена с «позиция + базовая единица» до «позиция + код единицы»; отображаемая цена осталась ценой за базовую единицу.
